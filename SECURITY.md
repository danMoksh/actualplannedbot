# Security Policy

## Supported Versions

Security updates are provided for the current active release.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | Yes |
| < 1.0   | No                |

## Reporting a Vulnerability

If you discover a potential vulnerability in the bot's command handling, file storage, or authentication mechanism:

1. **Do not create public GitHub issues**.
2. Report the vulnerability privately via **[GitHub Security Advisories](https://github.com/danMoksh/actualplannedbot/security/advisories/new)** or email **mokshdandotiya@gmail.com**.
3. Please provide a clear summary, reproduction steps, and impact.

## Response SLA

- **Acknowledgement**: Within 48 hours
- **Triage**: Within 5 business days
